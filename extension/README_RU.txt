OUR HOUSE HUNT IMPORTER v0.16.0

Расширение передаёт название агентства и адрес отделения для поиска сайта агентства. Также оно пытается получить точку Street View из исходного объявления.

Импорт использует упорядоченные фотографии и планы из данных исходного объявления. В карточке сохраняется исходный порядок. Для Zoopla используется исходный список медиа; при его отсутствии расширение проверяет галерею. Для Rightmove используются данные самого объявления.

Чтобы обновить установленное расширение, распакуйте файлы в его папку, откройте chrome://extensions и нажмите Reload. Проверьте, что версия расширения 0.16.0, затем обновите вкладку Our House Hunt. Сохранённые дома и пользовательские изменения находятся в базе сайта, а не в расширении.

Расширение также открывает Google Maps для чтения маршрутов: для этого Chrome запросит разрешение на доступ к www.google.com. Маршруты сохраняются сайтом только после полного расчёта.
